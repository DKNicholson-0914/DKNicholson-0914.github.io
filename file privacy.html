DKN Backup Privacy Policy

Updated October 21, 2026.

DKN Backup is a personal utility operated by the account owner. It uses rclone with read-only Google Drive access to download selected files and their metadata for personal backup.

Downloaded files, backup catalogs, logs, and authorization credentials are stored on the owner's computer and backup drives. Backup data and credentials are not published on this website.

The utility does not sell data, use it for advertising, or use it to train artificial intelligence models.

The owner controls how long local backups are retained. Revoking access in Google Account settings stops future authorized access but does not erase existing local backups.

This public information page is hosted by GitHub Pages, whose own privacy practices apply to website visitors.
